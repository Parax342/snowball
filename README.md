Well, mostly. I needed a little C for inputs to actually work.
It's really bad, COBOL was not meant for making games.

FLASHING LIGHTS WARNING! The screen flashes a ton during gameplay. I don't know if its fixable.

The code is not very good, I made this entirely for fun and also COBOL is really weird and bad

### How to compile:
- Install GnuCOBOL and make sure cobc.exe is on your PATH
- Change the second line of build.bat to the path of the default build config
- Run build.bat
